# Evaluación Física Voleibol

Ficha de evaluación física de voleibol: pruebas de salto, velocidad, agilidad, fuerza y resistencia, nivel físico por capacidad y plan de mejora por atleta.

Abrir la aplicación: https://garberhn70.github.io/evaluacion/

Los datos de los atletas se guardan solo en cada dispositivo (y, si se configura, en la copia privada en la nube). Este repositorio no contiene datos de atletas.
